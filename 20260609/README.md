\# 有限元平衡方程组的求解与误差分析



\## 硬件环境

CPU:：13th Gen Intel(R) Core(TM) i7-13700F (2.10 GHz)

内存：16GB

操作系统：Microsoft Windows 11 专业版



\## 软件环境

Python：3.14.0

NumPy：2.4.4

SciPy：1.17.1

json：2.0.9

Matplotlib：3.10.9

pypardiso：0.4.7

求解器：Intel MKL PARDISO（经由 pypardiso 接口调用）



\## 并行配置

线程数：24



\## 运行方法

1.直接运行

python 2\_4.py

2.仅运行特定模块

在 if \_\_name\_\_ == "\_\_main\_\_": 中注释或取消注释相应的函数调用。



\##程序将自动依次执行：

1.与2.3作业衔接（算例1、算例2）

2.三对角矩阵性能测试（n=10,100,500,1000）

3.非正定矩阵检测

4.病态矩阵误差分析（双精度 vs 单精度）

5.多载荷工况效率演示

6.大规模稀疏求解器调用（n=5000）

7.二维Poisson方程有限元求解（50×50, 100×100, 200×200）
