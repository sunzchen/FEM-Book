\##输出说明

1.任务1：形函数单位分解、Kronecker delta、导数求和验证

2.算例1：Kronecker delta（各单元最大误差）

3.算例2：10个随机点的单位分解与导数求和

4\.任务2/算例3：三种四边形的雅可比行列式检查

6\.任务4/算例4：线性与二次函数的 Patch Test（完备性检验）

7\.任务5：Poisson 方程求解（4×4、8×8、16×16 网格），每个单元输出节点数、单元数、自由度、非零元、条件数、最大误差、L2相对误差，并保存云图

8\.任务6：Q9 单元静力凝聚（原始与凝聚后矩阵大小）

9\.汇总表：所有网格和单元的 L2 相对误差与条件数表格
