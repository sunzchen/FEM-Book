\# 总体刚度矩阵组装与桁架结构求解



\## 环境要求

\- Python 3.14+

\- NumPy

\- json



\## 程序功能

1\.自动生成对号矩阵 LM

2\.计算二维桁架单元刚度矩阵

3\.直接组装总体刚度矩阵

4\.缩减法处理位移边界条件

5\.求解节点位移和约束反力

6\.后处理计算单元应力、轴力

7\.支持 JSON 文件输入模型数据



\## 运行方法

1\.使用内置算例

python truss\_solver.py



2\.从json文件读取模型

python truss\_solver.py <json\_file>



\## json输入文件格式

{

&#x20; "Title": "算例名称",

&#x20; "ndof": 2,

&#x20; "nnp": 3,

&#x20; "nel": 2,

&#x20; "nen": 2,

&#x20; "E": \[弹性模量列表],

&#x20; "CArea": \[截面积列表],

&#x20; "x": \[节点x坐标],

&#x20; "y": \[节点y坐标],

&#x20; "IEN": \[\[单元1节点1, 单元1节点2], \[单元2节点1, 单元2节点2]],

&#x20; "fixed\_dof": \[约束自由度编号(从1开始)],

&#x20; "fixed\_value": \[对应位移值],

&#x20; "force\_dof": \[载荷自由度编号(从1开始)],

&#x20; "force\_value": \[对应载荷值]

}



\## 输出示例

1\.总体刚度矩阵

2\.节点位移

3\.单元应力、轴力

4\.约束反力

5\.性质检查（对称性、奇异/非奇异）



\## 文件说明

truss\_solver.py – 主程序

truss1.json – 算例1输入文件（一维两单元）

truss2.json – 算例2输入文件（二维两杆桁架）



\## 注意事项

1\.程序内部使用 0‑based 自由度编号，JSON 中自由度编号从 1 开始，会自动转换

2\.单元连接 IEN 中的节点编号也采用 1‑based，内部转为 0‑based
