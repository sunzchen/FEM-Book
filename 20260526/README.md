\## 运行说明 (README)



\### 环境要求

\- Python 3.14+

\- NumPy



\### 运行程序

3D\_stiffness\_stress.py



\### 程序功能

1\.自动运行两个验证算例（一维杆单元、空间任意方向杆单元）

2\.输出单元长度、方向余弦、刚度矩阵、应变、应力、轴力

3\.验证刚度矩阵的对称性、刚体位移、特征值及物理意义

4\.检测退化单元（节点重合）并报错



\### 自定义输入

可在主程序 if \_\_name\_\_ == "\_\_main\_\_": 中修改节点坐标、弹性模量、截面积和位移数组，重新运行即可。
